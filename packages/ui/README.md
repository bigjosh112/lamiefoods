# @lamiefoods/ui

Presentational primitives shared across the monorepo.

Intentionally near-empty: the Lamie Foods design system has not been approved yet.
Only `cn` lives here for now. Components move here once a primitive is genuinely
used in more than one place — building the shelf before there is anything to put
on it is how shared packages turn into dumping grounds.

App-specific components stay in `apps/web/src/components`.
